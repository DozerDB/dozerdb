# DozerDB 5.26.32.0

Long-term-support release on Neo4j 5.26.32.

| | |
| --- | --- |
| Neo4j baseline | `5.26.32` (commit `27f24499b751708815d42c8cf26bfb6597b3516c`) |
| Components | core `5.26.32-1.1.0`, Browser `5.26.32.0`, plugin `5.26.32.0` |
| Runtime | Java 17 or 21; the Docker image ships Temurin 21 on Debian Trixie |
| Docker | `graphstack/dozerdb:5.26.32.0`, `graphstack/dozerdb:5.26` |

## What is in this release

- Neo4j 5.26.32 brings the upstream dependency and security updates of the
  5.26 line (Jackson, Netty, Jetty, Shiro, Bouncy Castle, log4j and others),
  Cypher planner fixes and the rewritten `neo4j-admin report`.
- Multiple databases: `CREATE`, `SHOW`, `STOP`, `START` and `DROP DATABASE`,
  with `SHOW DATABASES` reporting both the requested and the current status
  of every database and the configured limit `dbms.max_databases` (100 by
  default).
- Constraints: node and relationship property existence, node key and property
  type constraints are enforced on every write, including values changed by
  `SET` and labels added after the constraint exists.
- The release bundle gains the Windows archive and the shaded plugin JAR next
  to the Unix archive, each with a SHA-256 checksum.
- The plugin JAR works in a stock Neo4j Community `5.26.32` `lib/` directory
  on every platform; DozerDB is selected by entry point priority rather than
  by classpath order.

## Compatibility notes

- Data directories from earlier DozerDB 5.26 releases open unchanged; Neo4j
  5.26.32 is a maintenance release of the same store format.
- The Windows archive is verified by inspection of its contents and launchers;
  it is not run as part of the release checks.
- Neo4j's Cypher `WAIT` clause on database management commands is not
  supported.

## Verification

The release archives, the plugin JAR and the Docker image passed the packaged
smoke tests, the Cypher constraint and database lifecycle flow and the Browser
flow described in [building.md](../building.md). Checksums are published beside
each file on the GitHub release.
