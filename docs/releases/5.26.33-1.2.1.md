# DozerDB 5.26.33-1.2.1

DozerDB 1.2.1 on Neo4j `5.26.33`. Updates the Neo4j LTS baseline with upstream security and correctness fixes, repairs parameterized database lifecycle commands, and restores ALTER USER execution.

| Distribution version | `5.26.33-1.2.1` |

## What is in this release

- Neo4j 5.26.33 includes authentication concurrency and administration parameter-handling fixes, dependency updates, transaction-log and index transaction-state corrections, and Cypher planner and rewriting fixes.
- Parameterized STOP, START and DROP DATABASE commands now resolve database
  names consistently, including mixed-case values and quoted parameter names.
- ALTER USER can now resolve the registered security graph component.
- Metrics, query logging and `dbms.setConfigValue` retain the 1.2 feature set.
- Open GDS 2.13.15 is the companion plugin for this Neo4j version.

## Compatibility notes

- Use the plugin JAR with the exact Neo4j Community `5.26.33` baseline.
- Cross-line store migration is not validated by this release. Back up existing
  data before upgrading.
- Query logging remains enabled at VERBOSE by default. See
  [query logging](../monitoring/query-logging.md) for its settings and cost under load.
- The Windows archive is checked statically; its launchers are not executed
  on a Windows host in the release checks.
- The Cypher WAIT clause on database management commands remains unsupported.
